# Codex Skills

Personal maintained skills that should travel with this dotfiles repo.

This directory intentionally excludes:

- `.system/` built-in skills
- plugin and bundled skill caches
- dependency folders such as `node_modules/`
- generated bytecode, logs, and local runtime state

When a skill needs dependencies, track the source, manifest, lockfile, and setup
instructions. Do not vendor installed dependencies into this repo.
