# Packet: Integration

## Objective

Map local facts and sourced practices into a Pi-native implementation plan.

## Context

Pi must remain the user-facing tool. The plan may propose docs, templates,
skills, extensions, and evals, but not a wrapper around Pi.

## Do

- Accept practices that reduce decision variance.
- Reject practices that add orchestration without evidence.
- Define roles, routing rules, stop conditions, validation, and phases.

## Do Not

- Implement runtime changes.
- Add external dependencies.

## Expected Output

`results/integration.md` and `docs/pi-agentic-workflow-loop-plan.md`

## Verification

The final plan includes implementation order and acceptance criteria.
