# Packet: Web Research

## Objective

Collect current primary or recognized sources about deterministic agentic
workflow practices.

## Context

Research themes:

- agent loops and exit conditions;
- planner / builder / evaluator separation;
- guardrails and human review;
- evals and trace grading;
- prompt contracts and structured outputs;
- skills, hooks, and Pi primitives.

## Do

- Prefer primary sources and official docs.
- Label claims by confidence.
- Keep external frameworks as references unless they directly fit Pi.

## Do Not

- Rely on unsourced blog summaries when primary docs exist.
- Recommend external orchestration as the default.

## Expected Output

`results/research.md`

## Verification

Every accepted claim has a source URL.
