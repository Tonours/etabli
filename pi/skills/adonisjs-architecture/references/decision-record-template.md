# AdonisJS architecture decision record template

Use this template when a structural choice matters enough to record.

## Decision

State the chosen architecture in one sentence.

## Context

- feature or module involved
- constraints
- current drift or local conventions

## Recommended placement

- route
- middleware
- controller
- validator
- model/query
- service/action
- provider/event/command if relevant

## Native Adonis primitives

List the framework modules that should own the concern.

## Rejected alternatives

List the main alternatives rejected and why.

## Drift risks

State what would create framework drift here.

## Minimum proof

State the tests or review checks required before ship.
