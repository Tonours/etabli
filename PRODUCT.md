# Product context: native Claude Etabli cockpit

## Register

product

## Users

Developers using Claude Code and Etabli to resume work, understand a workflow
decision, inspect checks and review evidence. The current user asks for French
information that is understandable at a glance and demands less attention.

## Product Purpose

The `/etabli` pane answers what is happening, what needs attention and what to
do next. Eight views expose the canonical workflow and observations from the
current Claude session. It presents evidence without issuing permissions or
running the displayed next action.

## Brand Personality

Direct, calm, factual. Use the host's native terminal components and semantic
colors; keep the information readable in monochrome.

## Anti-references

Raw JSON as the main reading surface, equal prominence for every hash and
status, decorative dashboards, or reassuring status labels without evidence.

## Design Principles

- Lead with the state and the next useful action.
- Keep blockers, stale evidence and unknown values visible.
- Reveal source paths, hashes and complete records on demand.
- Use short French labels and consistent keyboard controls.
- Preserve the distinction between a request, a decision and current authority.

## Accessibility & Inclusion

Support keyboard navigation and narrow terminal panes. Express states in text
as well as color. Keep native host typography and focus behavior. No specific
accessibility certification is claimed.
