## Decisions
### Commit-message check lives in the existing `pr-body` guard
- Context: trailers reached pushed commits three times (force-pushes).
- Choice: parse the Bash command in the PreToolUse guard shared by Claude hooks and Pi.
- Rejected options: a git `commit-msg` hook (needs a global `core.hooksPath`, which overrides repo hooks).
- Rationale: one guard, already wired on both runtimes.
- Consequences: a shell-form parser that review rounds kept extending; rarer forms stay residual.

### Ambiguous credit words are case-sensitive
- Context: "generated by cursor movement" was refused.
- Choice: Cursor, Aider, Devin, Cline, AI, LLM count as a credit only capitalized; `gpt` matches only with an optional digit suffix.
- Rejected options: a wider tool list matched case-insensitively.
- Rationale: avoid false refusals in backend commit prose.
- Consequences: "generated with ai" in lower case passes.

### Handoff without a plan goes to a distilled vault note

- Choice: kept the owner's Q12 answer (vault note, distilled).
