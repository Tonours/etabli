## Outcome
The repository and fresh npm installer pin Pi coding-agent 1.0.3. The installer reads the version from pi/package.json, and pi/bun.lock freezes the dependency tree. Existing global installations are not upgraded by this change.

Repository package installation now reapplies the existing specialist disable-model-invocation policy. A malformed personal skill reports an actionable warning and does not abort installation of the remaining tools. The stamp checker and model-facing skill guard remain strict. Radius must carry DMI whenever its managed skill file is present, even when a package filter currently hides it.

The subscription-routing commit is included in the direct-main delivery authorized by the user's later request. No subagents, Claude-to-Z.ai store, third-party subscription login, paid benchmark or model request were activated.

## Decisions
### Exact repository pin and native compatibility evidence
- Choice: pin literal 1.0.3, frozen install from an empty isolated dependency tree, and read the same package pin for fresh installation.
- Validation: native offline startup with the tracked models.json, all eight available managed extension files, no active Task/delegation tools, and a synthetic 0.84.4 session resumed by 1.0.3.
- Limit: the external Pi Mobile bridge target is absent from this worktree. Its symlink and activation were unchanged. Real MCP server connections and authenticated provider requests were not exercised.

### Radius visibility convergence
- Choice: reuse the existing stamper and YAML parser, require Radius DMI independently of prompt visibility, and reapply flags after managed package installation.
- Fresh clones can resolve YAML from the globally installed npm Pi when local test dependencies are absent. Both resolution and failure controls are tested.
- Limit: stamping targets Pi's managed agent npm directory. Legacy global npm Radius installations must be moved into that managed directory; an unexpected rendered package skill still fails the native manifest guard.

### Subscription boundary
Muse subscription work remains recommended through the official Muse CLI. Pi 1.0.3 technically implements Meta OAuth; it remains experimental with unresolved CGU risk and is not enabled here. Claude Pro stays in native Claude Code. Only GLM 5.3 and Flash are enabled in the tracked Pi scope.
