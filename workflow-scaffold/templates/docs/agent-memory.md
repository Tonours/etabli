# Agent Memory

Durable lessons for future agent sessions live here.

Use one Markdown file per lesson, named in kebab-case. Start each file with a one-line summary, then record the correction or confirmed approach and why it matters.

Do not store transient run logs here. Keep `PLAN.md` for current execution state, `docs/project-context.md` for stable project facts, and `docs/plan/` for archived plans and long-run handoffs.

Before non-trivial work, read this directory after `docs/project-context.md`. Update existing lessons when possible, and remove lessons that are no longer true.
