# Plan Review

Follow `workflow/spec.md`.

1. Read `PLAN.md`.
2. Challenge goal, scope, steps, checks, assumptions, risks, and open questions.
3. Update `PLAN.md` in place.
4. Set `Status: CHALLENGED` if blockers remain.
5. Set `Status: READY` only when the minimal READY gate passes.
6. Return final status, blockers if any, and next action.

Do not implement. Do not create `REVIEW.md`.
